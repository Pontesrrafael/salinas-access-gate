# Glossário

| Termo | O que significa |
|---|---|
| **Admin/TI** | Perfil com acesso a tudo, inclusive às configurações. Pode trabalhar em qualquer outro perfil. |
| **Anonimização** | Retirar de um registro os dados que identificam a pessoa, mantendo só os números para estatística. |
| **Área de serviço** | Equipe que recebe chamados, como SSMA, Facilities, Meio Ambiente ou Suprimentos. |
| **ASO** | Atestado de Saúde Ocupacional. |
| **Atendente** | Membro da equipe de uma área que trata os chamados. |
| **Auditoria** | Registro de quem fez o quê, quando e de onde. Não pode ser alterado. |
| **Backlog** | Conjunto de chamados ainda não concluídos de uma área. |
| **Categoria** | Tipo de serviço dentro de uma área, por exemplo "Manutenção elétrica" em Facilities. |
| **Chamado** | Pedido feito a uma área pelo portal de serviços. |
| **Comissionamento** | Liberação de um veículo para circular na mina. |
| **DPO / Encarregado** | Pessoa responsável pelos assuntos de proteção de dados (LGPD). |
| **Duas etapas (MFA)** | Login que, além da senha, pede um código de 6 dígitos gerado no celular. |
| **Fila de atendimento** | Lista de chamados das áreas de que você participa. |
| **Gestor de área** | Perfil "semiadministrador" de uma área: acompanha o backlog e ajusta equipe, categorias, prazos e formulário da área. |
| **Horário comercial** | Período em que o prazo do chamado corre. Noites, fins de semana e feriados não contam. |
| **Impacto** | Quantas pessoas ou operações um problema afeta (A a D). |
| **LGPD** | Lei Geral de Proteção de Dados Pessoais (Lei 13.709/2018). |
| **Link externo** | Endereço temporário (72 h) para o próprio visitante preencher a solicitação de acesso. |
| **Nota interna** | Comentário no chamado visível só para a equipe da área. |
| **Pendente** | Chamado aguardando o solicitante ou um terceiro. O prazo de solução pausa. |
| **Perfil ativo** | Perfil com que você está trabalhando no momento. Define o menu e as permissões. |
| **Prioridade** | Ordem de atendimento, calculada a partir da urgência e do impacto. |
| **Prorrogação** | Aumento do prazo de solução de um chamado, sempre com motivo registrado. |
| **Quem está no site** | Lista de pessoas cuja última movimentação foi uma entrada. |
| **Segurança Patrimonial** | Marcação de usuário que autoriza visitas. |
| **SLA** | Prazo combinado para responder e solucionar um chamado. |
| **Solicitação de acesso** | Pedido para um visitante ou terceiro entrar numa data. Precisa ser aprovado. |
| **Solicitante** | Quem abre o chamado. Também é o perfil de quem só usa o portal de serviços. |
| **Solucionado** | Chamado que a equipe concluiu e que aguarda a aprovação do solicitante, ou o fechamento automático em 7 dias. |
| **SSMA** | Saúde, Segurança e Meio Ambiente. |
| **Transferir** | Mover um chamado para outra área ou categoria. |
| **Triagem** | Chamados sem atendente, aguardando distribuição. |
| **Urgência** | Quanto tempo um pedido pode esperar. |
| **Verificação SSMA** | Análise que marca uma pessoa como "Apto" ou "Não apto" para uma atividade de risco. |
